# 悬浮课表 — 技术方案

## 1. 技术选型

| 项 | 选择 | 理由 |
|---|---|---|
| 框架 | Electron（安装时取最新稳定版，实际版本号记入开发日志） | 支持无边框、透明窗口、托盘与 Windows 原生调用，网页技术写界面最快 |
| 渲染层 | 原生 HTML / CSS / JS，无框架、无打包器 | 单页小工具，保持零构建复杂度 |
| 打包 | electron-builder，target = `portable`（win x64） | 产出绿色单 exe |
| 运行时依赖 | koffi（唯一，纯系统调用所需：user32.dll SetWindowPos 置底。预编译原生模块，无需构建工具链；electron-builder 自动打包进 asar） | — |
| 开发依赖 | electron、electron-builder | — |

## 3. 窗口实现

- `BrowserWindow`：`frame:false`、`transparent:true`（**真半透明方案**）、`alwaysOnTop:false`（**桌面挂件模式**）、`resizable:true`、`minWidth/minHeight`、`skipTaskbar:true`、`show:false` + `ready-to-show` 后再显示（避免白屏闪烁）
- 置底实现（F3）：Electron 无置底 API，用 koffi 调 `SetWindowPos(HWND_BOTTOM=1, SWP_NOMOVE|SWP_NOSIZE|SWP_NOACTIVATE)`；时机 = 窗口 `show` 后 150ms + `blur` 时（点击可临时前置编辑，失焦自动回落）；koffi 加载失败时仅告警不崩溃
- 「恢复默认位置」（F12）：托盘右键菜单项，`win.setBounds(defaultBounds())` 并写回 schedule.json——窗口被拖丢时的救援入口（启动时越界校验仍兜底）
- 半透明实现注记：原用 `backgroundMaterial:'acrylic'`（Win11 系统磨砂），但实测 Electron 44.1.1 + 本机（Win11 26200，DPI 1.5）**未生效**——真实屏幕采样确认窗口完全不透明（诊断过程见开发日志）。现改为透明窗口 + CSS 自绘卡片（圆角 12px + 阴影），半透明可靠生效；若日后系统材质恢复可用再切换（两方案互斥，`transparent:true` 会禁用 backgroundMaterial）
- 圆角/阴影：透明窗口没有系统圆角与阴影，由 CSS 提供：卡片 `margin:8px` 内缩一圈 + `border-radius:12px` + `box-shadow`
- 分辨率注意：本机 scaleFactor=1.5，`screen.getPrimaryDisplay().scaleFactor` 参与真实屏幕采样坐标换算（见 SCHEDULE_SHOT 自检）
- 拖动/缩放：顶栏主体为 `-webkit-app-region: drag`；**所有可交互元素（格子、按钮）必须 `no-drag`**，否则无法点击（已知坑）
- 位置记忆：`window` 字段（x/y/width/height）存 schedule.json；启动时存在则恢复并校验仍在屏幕内（不在则回右下角）；不存在则放 `workArea` 右下角、偏移 24px

## 4. 进程与安全

- `contextIsolation:true`、`nodeIntegration:false`；渲染层一律通过 `preload.js` 中 `contextBridge` 暴露的最小 API 通信
- 暴露 API：`load()`、`save(data)`、`quit()`、`setAutoStart(bool)`、`getAutoStart()`、`version`
- 数据读写放在主进程（`fs`），渲染层只经 IPC

## 5. 数据格式（schedule.json）

```json
{
  "version": 1,
  "settings": {
    "semesterStart": "2026-09-07",
    "weekCount": 20,
    "periodsPerDay": 8,
    "periodTimes": [
      { "start": "08:00", "end": "08:45" },
      { "start": "08:55", "end": "09:40" },
      { "start": "09:50", "end": "10:35" },
      { "start": "10:45", "end": "11:30" },
      { "start": "11:40", "end": "12:25" },
      { "start": "14:00", "end": "14:45" },
      { "start": "14:55", "end": "15:40" },
      { "start": "15:50", "end": "16:35" }
    ],
    "opacity": 0.65,
    "autoStart": false
  },
  "window": { "x": 1200, "y": 700, "width": 640, "height": 480 },
  "viewWeek": 2,
  "weeks": {
    "3": { "0": ["高等数学", "", "", "体育", "", "", "", ""], "1": ["", "", "", "", "", "", "", ""] }
  }
}
```

- `weeks`：键 = 周序号（字符串，"1".."weekCount"）；值 = 天序号（"0"=周一 .. "4"=周五）→ 长度 `periodsPerDay` 的字符串数组（元素为课程名，空串=无课）
- `viewWeek`：最近查看的周，启动时恢复；缺失或越界（超出 1..weekCount）时回退当前周
- 当前周计算：`week = floor((本周周一 - semesterStart) / 7) + 1`，夹在 `[1, weekCount]`；`semesterStart` 为空时回退为第 1 周
- 保存策略：编辑确认后即保存；先写同目录临时文件，再备份旧文件为 `schedule.bak`，最后原子替换主文件。保存失败必须经 IPC 返回错误，不得静默吞掉。
- 缺省/损坏容错：主进程对全部字段做类型、范围与结构归一化；主文件不可读时优先从 `schedule.bak` 恢复，否则返回默认值，不崩溃。
- 数据目录（实现注记）：development 模式用 `app.getAppPath()`（工程根目录）；打包后 electron-builder `portable` 目标下 `process.execPath` 指向**临时解压目录**，必须用 `process.env.PORTABLE_EXECUTABLE_DIR` 取 exe 真实所在目录（非 portable 打包形态回退为 exe 所在目录）。该目录不可写时回退到 Electron `userData` 目录并记录警告。

## 6. 托盘图标与开机自启

- 托盘：`Tray` + `assets/tray.png`（由 `scripts/make-icon.js` 生成，纯 Node 无依赖：淡蓝圆角方块 + 白色课表行；同目录另有 256px `icon.png` / `icon.ico` 备打包用）。左键点击切换窗口显示/隐藏；右键菜单「显示 / 隐藏课表」「恢复默认位置」「退出」
- 开机自启：`app.setLoginItemSettings({ openAtLogin: bool, path: process.execPath })`。注：dev 模式下该 API 会把 electron.exe 设为自启项，自启功能只在**打包后的 exe** 上验收。

## 7. 打包

- 命令：`npm run dist`（electron-builder `--win portable --x64`，asar 默认开启）
- `productName` 用中文「悬浮课表」，`executableName` 用 `FloatingSchedule`（避免中文 exe 名带来的兼容问题）
- 图标：第一阶段先用 Electron 默认图标；阶段 5 若时间允许做一个淡蓝色简单 .ico（可选）

## 8. 已知风险

1. `backgroundMaterial` 与 `transparent:true` 互斥——当前采用透明窗口 + CSS 自绘卡片，不启用 Acrylic。
2. 便携版放置目录可能不可写——自动回退写入 `userData`，控制台记录实际数据目录。
3. 数据文件被手工编辑或写入中断——读取时归一化；主文件不可读时优先恢复 `.bak`。
4. 无任务栏入口——通过托盘左键切换显示/隐藏，右键菜单提供显示、隐藏、恢复默认位置与退出。
