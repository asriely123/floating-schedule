# 悬浮课表 — 设计规范（UI 实现标准）

> 写 UI 代码前必读。颜色、字号、间距、状态一律以本文为准；需要改动时先改本文再改代码。

## 1. 风格总则

磨砂淡蓝半透明卡片、圆角、柔和阴影；信息密度低、留白充分；全中文；视觉安静不花哨，动画克制（≤120ms）。

## 2. 色板

| 用途 | 值 |
|---|---|
| 窗口底色（透明窗口方案，覆于桌面上） | `rgba(214, 232, 248, 0.65)` |
| 卡片外框 | 卡片 `margin:8px` 内缩 + `border-radius:12px` + `box-shadow: 0 6px 24px rgba(31,55,86,0.22)`（透明窗口无系统阴影/圆角，CSS 补） |
| 格子底 | `rgba(255, 255, 255, 0.55)` |
| 格子 hover/编辑态底 | `rgba(255, 255, 255, 0.9)`，编辑态加 `1.5px #4A90D9` 描边 |
| 格子边框 | 1px `rgba(255, 255, 255, 0.7)` |
| 内分隔线 | 1px `rgba(61, 90, 128, 0.12)` |
| 主文字 | `#2E475D`（课名、星期表头、周数标题） |
| 次要文字 | `#5B7A99`（时间、翻页按钮） |
| 强调色 | `#4A90D9`（当前节底色、按钮 hover、编辑描边） |
| 今天列标记 | 列底色 `rgba(74, 144, 217, 0.16)` + 星期表头文字 `#2E5FA3` 加粗 |
| 当前节 | 实底 `#4A90D9`，白色文字，圆角 6px |
| 空格子提示 | hover 时淡显 `+`（`#5B7A99` 40% 透明度） |

| 用途 | 字号/字重 |
|---|---|
| 周数标题（第 N 周 / 共 M 周） | 14px / 600 |

| 时间文字 | 12px / 400 |

## 4. 布局

- 窗口最小尺寸 **460×320**，默认 **640×480**；默认位置 = 工作区右下角外偏移 24px
- 顶栏：`悬浮课表`、`第 N 周 ／ 共 M 周`（左）· `复制上周` `◀` `▶` `回本周` `⚙`（右），高 36px，留白 12px；周数为主信息（14px / 600），应用名为次要信息（13px）。在 **460×320 窄屏**下顶栏必须自动分成两行，标题/周数与操作按钮均完整可见，不得靠横向滚动或裁切。
- 网格：常规宽度左侧时间列 76px，5 天列均分；单元格最小 64×36；**行高随窗口高度弹性均分**（`#grid-body`/`.cell-row` flex 布局，行最小高 44px），内容超高时网格区滚动、星期表头吸顶；单元格圆角 6px，单元格间距 6px，内容内边距 4px 8px。窄屏（含 460px 最小宽度）时间列固定 72px、网格间距 4px，每个天列不得小于 64px；不足时优先让网格区滚动，不得压缩天列到 64px 以下。
- 设置浮层采用纵向 flex 布局：header 与 footer `flex: 0 0 auto` 固定可见，只有中间 body（包含节次列表）允许 `overflow-y:auto`；页面不得出现第二个滚动容器，滚动条只属于设置 body。
- 底部留白 12px
- 周数标题以下、网格以上留 8px

## 5. 交互

- **编辑格子**：双击格子 → 出现多行文本框（内容全选），Enter/失焦确认并保存，Shift+Enter 插入换行，Esc 取消；空格子 hover 显示 `+`（点击其他处触发失焦，同样保存当前编辑）。课程名与编辑内容保留换行显示；不得静默套用未在需求中声明的 30 字上限。
- **键盘与焦点**：课程格可用 Tab 聚焦，Enter/空格进入编辑；按钮和聚焦格显示强调色焦点环。「复制上一周」必须使用应用窗口内的模态确认层，禁止使用会触发桌面挂件 `blur → 置底` 的浏览器原生确认框；确认层默认聚焦「取消」，Tab 不得离开，Esc 取消，关闭后焦点回到「复制上周」。双击格子进入编辑时确保窗口与文本框同时获得键盘焦点。设置浮层使用模态对话框语义，Tab 在浮层内循环；关闭后焦点回到 ⚙；保存处理中禁用关闭、取消与 Esc。
- **提交与失败**：渲染层 `data` 是已提交的权威数据。格子编辑、◀ ▶ 翻周、「回本周」和「复制上周」均先持久化，只有持久化成功后才替换 `data`、更新网格或提交新的查看周；失败时保留当前对象和输入，不推进界面，并在受影响控件附近显示中文原因，可再次重试。
- **翻页**：◀ ▶ 切换周；「回本周」返回当前周并高亮周数标题中的当前周提示；切换无动画。第 1 周隐藏/禁用复制上一周，边界翻页按钮禁用。
- **复制确认层**：整窗半透明遮罩，居中小卡片；标题「复制上一周」，正文说明将覆盖本周现有课程，底部仅保留「取消」「确认复制」。确认层属于当前复制动作，不与设置浮层复用状态；打开、确认和取消均不得使 BrowserWindow 失焦。
- **高亮刷新**：`setInterval` 30 秒检查一次「今天/当前节」；仅当前查看周为本周时显示高亮。
- **设置浮层**：整窗浮层覆盖（非新窗口），半透明遮罩；含：每天课数（数字 4–14）、节次时间列表（开始/结束 time 输入 + 删除 + 「添加一节」）、总周数（1–30）、开学日期（date）、不透明度（滑块 0.5–1）、开机自启（开关）、按钮：保存 / 取消 / 退出程序。读取开机自启状态期间，开关与保存按钮不可提交；保存按钮提交时显示「保存中…」，只锁定设置面板；保存失败保留面板和已输入内容。
- **设置错误位置与类型**：所有设置错误都显示在设置面板内，不使用课表顶部或其他全局提示替代。自启读取错误、节次校验错误、设置保存错误必须分别标明原因并就近显示：自启读取错误靠近开机自启控件；节次校验错误靠近对应时间行/时间列表；设置保存错误靠近面板操作区。校验失败不提交，保存失败保留草稿并允许重试。
- **开学日期缺省**：`semesterStart` 为空时不显示今天列或当前节高亮；首次打开在顶部显示「请设置开学日期」，并提供可直接打开设置面板的「设置开学日期」入口。
- **节次边界**：每天 4 节时隐藏删除节次操作；每天 14 节时隐藏「添加一节」操作。两种边界都不显示可点击但无结果的控件。
- **控件状态**：所有可点击格子和按钮使用 `cursor: pointer`，并定义 hover、active、disabled 状态；禁用态使用 `cursor: not-allowed`，且不响应点击或键盘提交。
- **拖拽区域**：顶栏空白处 = `drag`；顶栏按钮、网格内所有格子 = `no-drag`（否则无法点击）
- 空课表首次启动：顶部提示「请设置开学日期」链接进入设置
