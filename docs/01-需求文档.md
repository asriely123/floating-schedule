# 悬浮课表 — 需求文档

- 版本：v1.0
- 日期：2026-09-04
- 状态：**已确认**（与用户逐项确认，含补充决策）

## 1. 项目定位

个人自用的 Windows 桌面悬浮课程表小工具。优先简单、快速完成、界面干净，不追求功能堆砌。界面全中文。

## 2. 功能需求

### 2.1 窗口（F1–F4）

| 编号 | 需求 |
|---|---|
| F1 | 无边框窗口，默认显示在桌面右下角 |
| F2 | 磨砂半透明、淡蓝色、简洁美观 |
| F3 | **桌面挂件模式**：窗口只在桌面之上、其他一切窗口**之下**（不置顶）；点击窗口可临时前置编辑，失焦后自动回落到底层 |
| F4 | 鼠标可拖动到任意位置；可拖拽边角改变大小（有最小尺寸）；重启后记住位置和大小 |
| F12 | 通知区域托盘小图标：左键点击切换显示/隐藏；右键菜单含「显示 / 隐藏课表」「恢复默认位置」（窗口拖丢时救援回右下角）「退出」 |

### 2.2 课表（F5–F10）

| 编号 | 需求 |
|---|---|
| F5 | 课表为「周一~周五 × 每天 M 节」的格子矩阵，格子内显示课程名；课程名支持多行显示与编辑 |
| F6 | 每天课数 M 可在设置中调整，格子行数随之变化 |
| F7 | 每节课的起止时间可在设置中逐条自定义 |
| F8 | 课表按周翻页：每页为「第 N 周」，**每周内容独立编辑**；提供 ◀ ▶ 翻页、「回本周」；启动恢复上次退出时查看的周（首次使用或周数越界时定位当前周） |
| F9 | 「复制上一周」按钮：一键将上周全部内容复制到本周 |
| F10 | 当前查看周为本周时，高亮当前天（今天所在列）和当前节（正在上课的节次），自动刷新；浏览历史或未来周时不显示“当前”高亮 |

- 格子编辑：双击进入编辑；`Enter` 保存，`Shift+Enter` 插入换行，`Esc` 取消，失焦保存。
- 键盘操作：课表格子可聚焦，按 `Enter` 或空格进入编辑；设置浮层打开后焦点留在浮层内，关闭后回到打开设置的按钮。

### 2.3 设置项（F11 及配套）

| 设置项 | 默认值 | 说明 |
|---|---|---|
| 每天课数 | 8 | 可调，范围 4–14 |
| 节次时间表 | 每节 45 分钟、间隔 10 分钟的占位作息 | 逐条编辑起止时间 |
| 总周数 | 20 | 可调，范围 1–30 |
| 开学日期 | 无（首次打开时提示设置） | 第一周周一，用于计算当前周（补充项：F8「自动定位当前周」所必需） |
| 开机自启（F11） | 关 | 设置中一键开关 |
| 窗口不透明度 | 0.65 | 滑块调节（补充项：半透明深浅可调） |
| 退出程序 | — | 无边框窗口没有系统关闭按钮，设置面板内提供「退出程序」入口 |

### 2.4 数据

- 数据优先存于程序 exe 同目录的 `schedule.json`；目录不可写时回退到用户数据目录。保存前自动备份旧文件为 `schedule.bak`，主文件损坏时自动尝试从备份恢复。
- 换电脑：拷走 exe + schedule.json 即可

### 2.5 非功能要求

- 绿色免安装：打包为单文件 exe，双击即用
- 除桌面置底所需的 koffi 外，不引入额外运行时依赖，启动快
- 窗口不占任务栏（更像桌面挂件），入口集中在设置面板

## 3. 明确不做（v1 范围外）

周末显示、单双周模式、课程分组/配色、上课提醒、拖拽排序、多套课表切换、云同步、英语界面。若后期需要再追加需求并更新本文件。
